# The Agentic AI Academy

> A structured path from **zero to production-grade AI engineering** — agents, RAG, LLMs, MCP, and everything in between.

🟢 **100% Free** | 🔓 **Open Source** | 👥 **Community-Driven** | 📜 **MIT Licensed**

## About

The Agentic AI Academy is a free, comprehensive learning platform designed to teach developers how to build real, production-grade AI agents from scratch. Learn to master LLMs, RAG systems, agent frameworks, and modern AI engineering practices—with no paywalls, ever.

## 📊 By the Numbers

- **26** course modules across 3 phases
- **15+** RAG patterns covered
- **5k+** learners projected by month 18
- **∞** Cost to join (it's free!)

## 🎯 Three Phases, One Destination

### Phase 1: AI & LLM Foundations (Beginner)
*8–10 weeks · ~6 hrs/week · 8 modules*

Build your AI foundation from first principles:
- What is AI? History & modern stack
- Understanding LLMs & transformers
- Prompt engineering mastery
- AI APIs & developer setup
- Intro to AI agents
- Embeddings & vector similarity
- Your first RAG system

**Capstone:** Working AI assistant

---

### Phase 2: Agents & RAG Engineering (Intermediate)
*10–12 weeks · ~10 hrs/week · 9 modules*

Deep dive into real-world agent systems:
- LangChain deep dive
- Advanced RAG — all 15 patterns
- LangGraph, CrewAI & AutoGen
- Tool use & function calling
- Google ADK & AWS Bedrock
- Claude Code & AI coding tools
- MCP: Model Context Protocol

**Capstone:** 4-agent research engine

---

### Phase 3: Production AI Systems (Advanced)
*12–16 weeks · ~14 hrs/week · 9 modules*

Master enterprise-grade AI engineering:
- Agentic software engineering
- Multi-agent architecture
- GraphRAG & Self-RAG
- Fine-tuning with LoRA/QLoRA
- AI security & prompt injection defense
- Cloud deployment & CI/CD
- AI Engineer Toolkit 2026

**Capstone:** Production open-source AI system

---

## 🛠️ Build Real Projects

Learn by building:

- **AI Research Engine** — A 4-agent system with Planner, Researcher, Writer & Reviewer powered by CrewAI and hybrid RAG
- **Advanced RAG Pipeline** — Production RAG with metadata filtering, hybrid search, contextual compression and RAGAS evaluation
- **MCP Server** — A published MCP server connecting your agent to external APIs (GitHub, Slack, or your own)
- **Deployed AI App** — Production-grade system on cloud with CI/CD, monitoring via Langfuse, and cost tracking
- **Agentic REST API** — Use a coding agent to autonomously build, test, and document a REST API
- **Fine-tuned LLM** — Domain-specialized model using LoRA/QLoRA with evaluation and HuggingFace hosting
